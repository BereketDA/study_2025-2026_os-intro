# Теоретическая часть

В работе используются сценарии Bash, условные конструкции, циклы и системные команды. Упрощённый семафор основан на файле-блокировке: процесс проверяет наличие файла, создаёт его на время использования ресурса и удаляет после завершения работы. Для просмотра справки скрипт проверяет наличие файла страницы руководства и передаёт его содержимое командам `zcat` и `less`. Случайные буквы выбираются из строки алфавита с использованием переменной `RANDOM`.

# Материалы и методы

Выполнение работы проводилось в командной оболочке Bash. Были подготовлены три файла: `semaphore.sh`, `myman.sh` и `random.sh`. Для проверки использовались команды запуска скриптов и наблюдение за выводом терминала.

# Выполнение лабораторной работы

## Задание 1. Упрощённый механизм семафоров

Скрипт `semaphore.sh`:

```bash
#!/bin/bash
RESOURCE="resource.lock"
T1=5
T2=3

echo "Process $$ waiting for resource..."
while [ -f "$RESOURCE" ]
do
    echo "Process $$: resource is busy, waiting..."
    sleep 1
done

echo "Process $$: resource is free, capturing it"
touch "$RESOURCE"
echo "Process $$: using resource for $T2 seconds"
sleep $T2
echo "Process $$: releasing resource"
rm -f "$RESOURCE"
echo "Process $$: done"
```

Результат: два процесса (PID 8585 и 8608) успешно использовали ресурс по очереди.

## Задание 2. Реализация команды man

Скрипт `myman.sh`:

```bash
#!/bin/bash
CMD="$1"
if [ -z "$CMD" ]; then
    echo "Usage: $0 <command>"
    exit 1
fi
FILE="/usr/share/man/man1/$CMD.1.gz"
if [ -f "$FILE" ]; then
    zcat "$FILE" | less
else
    echo "No manual entry for $CMD"
fi
```

Результат: `./myman.sh ls` показал справку, а `./myman.sh nonexistentcmd` вывел сообщение об отсутствии справочной страницы.

![Результаты 2: Реализация команды man](image/result2.png){#fig-002 width=70%}

## Задание 3. Генерация случайных букв

Скрипт `random.sh`:

```bash
#!/bin/bash
ALPHABET=abcdefghijklmnopqrstuvwxyz
LENGTH=$1
for ((i=0; i<LENGTH; i++))
do
    echo -n ${ALPHABET:RANDOM%26:1}
done
echo ""
```

Результат: сгенерирована последовательность `tnoscbrlcgwfxby`.

# Обсуждение результатов

### Ответы на контрольные вопросы

**1. Найдите синтаксическую ошибку в следующей строке: `while [$1 != "exit"]`**

Ошибка: отсутствуют пробелы после `[` и перед `]`. Правильно: `while [ $1 != "exit" ]`.

**2. Как объединить (конкатенация) несколько строк в одну?**

`str1="Hello"`, `str2="World"`, `result="$str1 $str2"`.

**3. Найдите информацию об утилите seq. Какими иными способами можно реализовать её функционал при программировании на bash?**

`seq` генерирует последовательность чисел. Альтернатива: цикл `for ((i=1; i<=N; i++))`.

**4. Какой результат даст вычисление выражения `$((10/3))`?**

Результат: `3` (целочисленное деление).

**5. Укажите кратко основные отличия командной оболочки zsh от bash.**

zsh имеет более мощное автодополнение, улучшенную работу с массивами и поддержку плагинов.

**6. Проверьте, верен ли синтаксис данной конструкции: `for ((a=1; a <= LIMIT; a++))`**

Да, синтаксис верен, если переменная `LIMIT` определена.

**7. Сравните язык bash с какими-либо языками программирования. Какие преимущества у bash по сравнению с ними? Какие недостатки?**

Преимущества: простой синтаксис, работа с файлами и автоматизация. Недостатки: низкая скорость, слабая типизация и ограниченные структуры данных.
