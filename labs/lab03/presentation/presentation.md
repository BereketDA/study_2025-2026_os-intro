# Основные элементы Markdown

## Разметка текста

- Заголовки: `#`, `##`, `###`.
- Полужирное начертание: `**bold**`.
- Курсив: `*italic*`.
- Маркированные списки: `-`.
- Нумерованные списки: `1.`.
